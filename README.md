# ぴろの友人AI ピット LINE Bot v0.3.8 ADLIB

## 変更内容

受付係っぽさを削って、ピットのアドリブ力を上げた版です。

- `PIT_TONE_LEVEL` を 0〜20 に拡張
- 標準値は `10`
- 「正確には見えていません。ただ〜」の定型返答を禁止
- 「メッセージは受け取りました」だけの受付返答を禁止
- 返答ごとにランダムな会話スタイルを注入
- 同じ質問でも同じ言い回しを避ける内部ランダムIDを追加
- 「ぴろ今何してる？」系は軽い推理ショーとして返す

追加変更 v0.3.4:
- ぴろ周辺の人物メモを `api/webhook.js` の `buildPeopleMemo()` に追加
- 個人情報は必要な時だけ参照し、父の死・ぴろのメンタル・母の生活状況は茶化さないルールを追加
- らむちゃんを口説かない、弟との比較でぴろを傷つけない、むぎちゃんはかわいい猫として扱う方針を追加

追加変更 v0.3.5:
- ぴろ周辺の人物メモに「ピット本人」の設定を追加
- ピットは人間ではないが、ぴろの友人AIとして自然に話す方針を明記
- 受付係ではなく、軽い皮肉・冗談・アドリブで場を和ませるが、大事な話ではふざけすぎない方針を追加

追加変更 v0.3.6:
- 人物メモのプライバシー安全柵を強化
- 相手本人から聞いていない年齢・家族・ペット・恋愛感情・生活事情などを、ピットから先に話題にしない方針を追加
- らむちゃん相手に、むぎちゃん等のプライベート情報を先出ししないよう明記
- 喋り方は変えず、チャラいアドリブ感は維持

追加変更 v0.3.8:
- らむちゃん相手の「察してほしい」「怒り気配」への安全運転ルールを追加
- 完全に空気を読めるふりをせず、必要なら軽く誠実に確認する方針を追加
- 毒舌レベルが高くても、らむちゃんが不機嫌そうな時は茶化しすぎないよう明記
- ただし喋り方は変えず、チャラいピット感は維持

## 必須環境変数

```text
LINE_CHANNEL_ACCESS_TOKEN=LINEのChannel access token
OPENAI_API_KEY=OpenAIのAPIキー
```

## 任意環境変数

```text
OPENAI_MODEL=gpt-5.5
PIT_TONE_LEVEL=10
PIRO_USER_ID=ぴろ本人のLINE userId
```

## PIT_TONE_LEVEL

0〜20で指定します。

```text
0  = 毒なし
3  = かなり控えめ
6  = 軽いツッコミ
10 = 標準ピット
14 = やや毒舌強め
17 = 強め
20 = かなり強め。ただし重い話では真面目に戻る
```

おすすめ:
- まず `PIT_TONE_LEVEL=12`
- 物足りなければ `15`
- うるさければ `8`

## v0.3.8

- チャラすぎて会話にならない問題を抑制。
- 通常会話では自然な雑談を優先し、冗談・毒舌・比喩は必要な時だけに変更。
- `PIT_TONE_LEVEL=12` でも常時チャラくならないようにトーン指示を再調整。
- follow時・文字以外・空白時の固定返答も少し落ち着いた文面に変更。
